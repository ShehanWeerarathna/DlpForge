DlpForge

A free Windows app that puts a friendly interface on top of yt-dlp. Paste a link, pick video or audio and a quality, and download.

Download View on GitHub
Version 0.2 · Windows 10 / 11 · GPL-3.0

Features

Paste, drop or search

Always-visible link bar. Paste links, type words to search, or drop links and .txt lists. Quick download skips the card.

Pick the format

Video or audio, quality presets from 2160p to 360p, container or audio format, or an exact-format table.

Playlists

Every item listed with checkboxes, select all, none or invert, and Shift/Ctrl multi-select.

Download queue

1 to 10 parallel downloads with live progress, speed and ETA. Pause, resume, cancel, retry. Survives restarts.

Folders and templates

A folder per download type and file name templates with a live preview.

Embed extras

Thumbnail, metadata, chapters and subtitles embedded in the file. Edit the title and artist first.

Cut and split

Download only parts of a video on a timeline or by chapter, split by chapters, and remove sponsors with SponsorBlock.

Schedule and tray

Start downloads at a set time. Tray mode keeps DlpForge running with the window closed.

Power tools

Browser cookies, saved command templates, extra yt-dlp arguments and a built-in terminal.

History and logs

Searchable, sortable history with thumbnails, and a log viewer for every download.

Tools managed for you

Installs and updates yt-dlp, FFmpeg and Deno, switches yt-dlp channels and rolls back versions.

Fits Windows

Toast notifications, taskbar progress, light and dark themes, and a portable mode.

Download

Get DlpForge-<version>-win-x64.zip from Releases, unzip it and run DlpForge.exe. It needs Windows 10 or 11 (64-bit) and nothing else.

The exe isn't code-signed yet, so Windows may say “Windows protected your PC”. Click More info, then Run anyway. On first start, click Install tools to download yt-dlp, FFmpeg and Deno.

Build from source

Requires Windows 10 or 11 (x64) and the .NET 10 SDK.

git clone https://github.com/ShehanWeerarathna/DlpForge.git
cd DlpForge
dotnet run --project src/DlpForge.App

On first start, open Settings > Tools to download yt-dlp, FFmpeg and Deno. DlpForge also uses copies already on your PATH.
